⚙️ One-time setup

Show setup steps
1. Create a free project at supabase.com.
2. In your Supabase project, go to SQL Editor and run:
create table course_access (
  id uuid primary key default gen_random_uuid(),
  user_id uuid references auth.users(id) not null,
  course_id text not null,
  granted_at timestamptz default now(),
  unique(user_id, course_id)
);

alter table course_access enable row level security;

create policy "Users can view their own access"
  on course_access for select
  using (auth.uid() = user_id);
3. Go to Project Settings → API, copy your Project URL and anon public key.
4. Paste them into SUPABASE_URL and SUPABASE_ANON_KEY near the bottom of this file's <script> tag, then reload this page.
5. To test "granting access": sign up on this page, then in Supabase go to Table Editor → course_access and manually add a row with your user's ID and course_id = test-course. Reload this page while logged in to see it unlock.
